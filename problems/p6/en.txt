# Problem 6: REST API (Original Unconstrained)

Create a simple REST API using Node.js and Express.js that manages a collection of books. The API should support:

1. GET /books - List all books (with optional query params for filtering by genre, author, or status)
2. GET /books/:id - Get a single book by ID
3. POST /books - Create a new book (title, author, genre, publishedYear, isRead)
4. PUT /books/:id - Update an existing book
5. DELETE /books/:id - Delete a book
6. GET /stats - Return statistics: total books, books by genre, books read vs unread

Use in-memory storage (no database). Include proper error handling and validation. Add JSDoc comments for all endpoints.
