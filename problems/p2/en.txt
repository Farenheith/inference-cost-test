# Problem 2: REST API with Express

Create a simple REST API using Node.js and Express.js that manages books. Output ONLY the code - no explanations, no markdown headers, no README.

Requirements:
- GET /books - List all books (query params: genre, author, isRead)
- GET /books/:id - Get single book by ID
- POST /books - Create book {title, author, genre, publishedYear, isRead}
- PUT /books/:id - Update existing book
- DELETE /books/:id - Delete book
- GET /stats - Return stats: total, byGenre, readCount

Implementation rules:
1. Use in-memory array (no database)
2. Put ALL routes and handlers in a single app.js file
3. Use inline arrow functions for route handlers (not separate function declarations)
4. No JSDoc comments, no error handling middleware
5. Return JSON responses directly with res.json()
6. Include package.json with express dependency

Output format: Just the code files, nothing else.
