# Problema 2: API REST com Express

Crie uma API REST simples usando Node.js e Express.js que gerencia livros. Saída APENAS o código - sem explicações, sem cabeçalhos markdown, sem README.

Requisitos:
- GET /books - Listar todos os livros (params query: genre, author, isRead)
- GET /books/:id - Obter único livro por ID
- POST /books - Criar livro {title, author, genre, publishedYear, isRead}
- PUT /books/:id - Atualizar livro existente
- DELETE /books/:id - Excluir livro
- GET /stats - Retornar estatísticas: total, byGenre, readCount

Regras de implementação:
1. Usar array em memória (sem banco de dados)
2. Colocar TODOS os rotas e handlers em um único arquivo app.js
3. Usar funções arrow inline para handlers de rota (não declarações de função separadas)
4. Sem comentários JSDoc, sem middleware de tratamento de erros
5. Retornar respostas JSON diretamente com res.json()
6. Incluir package.json com dependência express

Formato de saída: Apenas os arquivos de código, nada mais.
